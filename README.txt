FOLIO STUDIO — программа для портфолио (Windows / macOS)

ЗАПУСК БЕЗ УСТАНОВКИ (для проверки)
  npm install
  npm start

СОЗДАТЬ УСТАНОВЩИК
  Windows: установите Node.js (nodejs.org, LTS) и дважды нажмите «Установить-Windows.bat».
           Установщик появится в папке dist (файл с названием Setup ... .exe).
  macOS:   дважды нажмите «Установить-Mac.command». В папке dist появится .dmg.
  Без установки Node.js: загрузите эту папку в репозиторий GitHub, откройте вкладку Actions,
  запустите «Build installers» — готовые .exe и .dmg можно скачать из результатов сборки.

ДАННЫЕ
  Хранятся на вашем компьютере (папка данных приложения). Резервная копия и восстановление — в разделе «Резервная копия».
